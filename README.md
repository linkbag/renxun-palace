# 后宫仁薰传 · 十一日回宫

创炉三十三年，离宫十一日。满城恭迎薰妃，只有宫门请他去排访客队。你来填那一栏——上工，讨说法，还是取饭盒？

**[入宫开戏](https://linkbag.github.io/renxun-palace/)**

![后宫仁薰传封面](assets/cover.webp)

这是一出免费的中文宫闱商战互动短剧。你先演创炉人黄仁薰，离宫后换珂莱特守炉，再坐上长案会的首席，亲手验最后一张货单。全剧九折，家笺、副钥与底稿会改变家门口、夜班炉前和报馆里的结局。首幕那张访客签也有回音。

## 怎么玩

- 手机和桌面浏览器都可以开戏。点人物名字翻小传，在戏目中回看已演的折子。
- 浏览器自动保存进度，包括选项回话与解到一半的题。回到同一浏览器、同一网址，选择「接着上回」。重演会沿用进入该折时的信物。
- 可以全程用键盘操作。吊桥既能按住再松开，也能分两次点按。声效默认关闭，可在剧场或戏中切换。
- 离线游玩可下载整个仓库，解压后打开 `index.html`。浏览器若限制本地文件存档，可在此目录运行 `python -m http.server 8000`，用 `http://localhost:8000` 打开。

## 片尾

本作为非官方戏拟。故事借用《后宫甄嬛传》的人物关系与戏剧结构，结合截至 2026 年 11 月 24 日的公开记录。宫廷对白、家书与验单过程为原创虚构。游戏内「片尾与取材」提供公司公告、SEC 文件、访谈和原剧分集梗概。
